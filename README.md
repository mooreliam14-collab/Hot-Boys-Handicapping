# Hot Boys Handicapping

Weekly NFL picks tracker for the group: each week's slate by kickoff window, live scoring from ESPN's public feed, and running standings.

- `index.html` – the tracker page
- `live.js` – reads live scores and player stats from ESPN in the viewer's browser and grades open bets
- `data/weeks.json` – every week's games, bets and final results (updated weekly). Each week's `driver` is the person who placed that week's slip; it shows in the top-right corner of the week.
